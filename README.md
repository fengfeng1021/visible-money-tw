# 看得見的錢

七個台灣人每年真的會遇到的財務決策，做成可以親手拖動、輸出分布與情境比較、每個數字都能攤開看法源的互動模型。

**線上版：** https://fengfeng1021.github.io/visible-money-tw/

純靜態網站。沒有帳號、沒有後端、沒有分析追蹤，所有計算都在瀏覽器裡完成，你填的數字不會離開自己的裝置。

## 這些工具跟別人不一樣的地方

1. **輸出分布與情境，不輸出一個數字。** 你要知道的是「我離那條線多遠」、「換個起始日會差多少」，不是一個孤零零的答案。每張單據都能同時擺好幾個情境比較。
2. **資料不足就拒答。** 樣本不夠、法規還沒上路、模型不適用時，畫面直接說「這個問題現在回答不了」並給出可回答的範圍。
3. **每個數字都能攤開看公式與法源。** 稅率、級距、費率、給付係數全放在有版本標記的常數檔裡，畫面上永遠看得到資料版本，而且可以自己改。
4. **資料不離開你的瀏覽器。** 情境用 localStorage 存本機，要分享就把整組數字編進網址。
5. **不做單向恐嚇，也不做單向鼓吹。** 呈現壞情境時同時給誠實的對照，結論交還使用者。

## 技術

零建置步驟。純 HTML + CSS + 原生 ES modules，GSAP 內嵌在 repo 裡。任何一頁用瀏覽器直接開就能跑。

```
index.html                 首頁（唯一的 Persuade 版面）
assets/
  css/tokens.css           設計代幣：紙色、墨色、語意色、字級、間距
  css/base.css             基礎排版
  css/components.css       元件庫（單據、填寫格、滑桿、四聯、印記、帳列表…）
  css/hub.css              首頁專用版面
  js/core/format.js        數字與日期格式化（台灣用語、民國年、萬／億）
  js/core/state.js         狀態、localStorage、網址情境編碼
  js/core/motion.js        動效語彙（逐行推出／複寫壓力／蓋章／數字滾動…）
  js/core/plot.js          Canvas 圖表引擎（線、面積、百分位帶、直方圖、堆疊）
  js/core/fin.js           共用金融數學（攤還、IRR／XIRR、拔靴、累進稅、補充保費）
  js/core/ui.js            元件行為（滑桿、填寫格、四聯、虛擬捲動表格…）
  js/core/thumb.js         首頁的招牌視覺形狀草稿
  data/*.json              法規常數（附法源與資料版本）
  data/market/*.json       台股 ETF 還原權息月序列
apps/<slug>/               七個工具，各自一個 index.html + app.css + app.js
tools/                     資料建置與截圖驗收腳本（不參與網站執行）
```

### 設計世界

台灣多聯式複寫單據。四種紙色承載並存情境；台灣制「漲紅跌綠」是語意色；印泥靛藍是唯一的強調色；全站圓角 0；髮絲格線、騎縫虛線、底線式填寫格、硃砂印記；數字一律等寬並對齊到同一條格線。

動效只在能說出「它讓使用者理解了什麼」時才出現，一頁只花一個招牌動效，全部尊重 `prefers-reduced-motion`。

## 本機執行

不需要安裝任何東西，但因為用了 ES modules，要用一個靜態伺服器開（直接雙擊 `index.html` 會被瀏覽器的 CORS 政策擋下）：

```bash
npx serve -l 4411 .
```

然後開 http://localhost:4411

### 重建市場資料

```bash
node tools/build-market-data.mjs     # 從臺灣證券交易所逐月抓取並合成還原權息序列
node tools/fill-market-gaps.mjs      # 補上被節流擋掉的月份
```

TWSE 會對連續請求回 307 導流到節流頁，所以建置腳本本身有節流與退避，補洞腳本再跑一次更慢的第二輪。

### 版面與截圖驗收

```bash
node tools/probe.mjs "http://localhost:4411/apps/mortgage-cliff/" 390
node tools/shot.mjs .shots "http://localhost:4411/"
```

Windows 上瀏覽器視窗有最小寬度（約 500px），所以 `chrome --window-size=390` 拍出來其實是 500px 版面被裁掉右邊。這兩支腳本改用 CDP 的 `Emulation.setDeviceMetricsOverride` 做真正的裝置模擬。

## 資料來源與免責

法規常數放在 `assets/data/*.json`，每一項附法源條號與資料時點，並在 UI 上顯示資料版本徽章。市場資料來自臺灣證券交易所公開資訊（`www.twse.com.tw/rwd/*`），離線建置後 committed 進 repo，執行期不呼叫任何外部 API。

本站為獨立試算工具，不是稅務、法律或投資建議，也不做任何導流或媒合。正式金額以主管機關核定為準：綜合所得稅以財政部、勞保給付以勞動部勞工保險局、補充保費以中央健康保險署、貸款條件以承貸銀行為準。市場資料僅供研究用途，不保證即時或無誤。
